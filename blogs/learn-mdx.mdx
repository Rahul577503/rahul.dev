# MDX Mastery: Complete Guide to Markdown + JSX

_Published on January 3, 2026_

MDX is a powerful format that combines Markdown's simplicity with React's interactivity. Write documentation, blogs, and content with embedded components for a rich, interactive experience.

---

## What is MDX?

**MDX = Markdown + JSX**

```mdx
# Hello World

This is regular Markdown.

<CustomComponent prop="value">
  But you can also use React components!
</CustomComponent>

And back to Markdown.
```

**Why MDX?**:

- ✅ Write content in Markdown
- ✅ Embed React components
- ✅ Import and use JavaScript
- ✅ Type-safe with TypeScript
- ✅ Perfect for docs and blogs

## Basic Markdown Syntax

### Headers

```md
# H1 Header

## H2 Header

### H3 Header

#### H4 Header

##### H5 Header

###### H6 Header
```

### Text Styling

```md
**Bold text**
_Italic text_
**_Bold and italic_**
~~Strikethrough~~
`Inline code`
```

Renders as:

**Bold text**  
_Italic text_  
**_Bold and italic_**  
~~Strikethrough~~  
`Inline code`

### Lists

**Unordered**:

```md
- Item 1
- Item 2
  - Nested item
  - Another nested
- Item 3
```

**Ordered**:

```md
1. First item
2. Second item
3. Third item
```

**Task Lists**:

```md
- [x] Completed task
- [ ] Incomplete task
- [ ] Another task
```

## MDX-Specific Features

### Importing Components

```mdx
import { Button } from "./components/Button";
import Chart from "./components/Chart";

# My Post

Here's a button:

<Button variant="primary">Click me</Button>

And a chart:

<Chart data={salesData} />
```

### Using JavaScript

```mdx
export const author = "Rahul Maurya";
export const publishDate = new Date("2026-01-03");

# {author}'s Blog

Published on {publishDate.toLocaleDateString()}
```

### Inline Expressions

```mdx
The answer is {2 + 2}.

Today is {new Date().toLocaleDateString()}.

Random number: {Math.floor(Math.random() \* 100)}
```

## Advanced Patterns

### Custom Components

Replace default HTML elements:

```mdx
import { CustomHeading, CustomLink } from "./components";

export const components = {
  h1: CustomHeading,
  a: CustomLink,
};

# This uses CustomHeading

[This uses CustomLink](https://example.com)
```

### Interactive Examples

```mdx
import { Counter } from "./components/Counter";

# Interactive Counter

<Counter initialValue={0} />

Try clicking the buttons above!
```

### Code Playgrounds

```mdx
import { CodePlayground } from "./components/CodePlayground";

<CodePlayground
  code={`
function greet(name) {
  return \`Hello, \${name}!\`;
}

console.log(greet('World'));
`}
language="javascript"
/>
```

## MDX with Next.js

### Setup

```bash
npm install @next/mdx @mdx-js/loader @mdx-js/react
```

```javascript
// next.config.js
const withMDX = require("@next/mdx")({
  extension: /\.mdx?$/,
  options: {
    remarkPlugins: [],
    rehypePlugins: [],
  },
});

module.exports = withMDX({
  pageExtensions: ["ts", "tsx", "js", "jsx", "md", "mdx"],
});
```

### Creating MDX Pages

```mdx
---
title: "My Blog Post"
date: "2026-01-03"
---

# {frontmatter.title}

Published on {frontmatter.date}

Your content here...
```

### Dynamic MDX

```tsx
import { MDXRemote } from "next-mdx-remote/rsc";

export default async function Post({ params }) {
  const post = await getPost(params.slug);

  return (
    <article>
      <h1>{post.frontMatter.title}</h1>
      <MDXRemote source={post.content} />
    </article>
  );
}
```

## Best Practices

### 1. Organize Components

```
components/
├── mdx/
│   ├── Callout.tsx
│   ├── CodeBlock.tsx
│   ├── Image.tsx
│   └── index.ts
└── ...
```

### 2. Use Frontmatter

```mdx
---
title: "Post Title"
date: "2026-01-03"
author: "Rahul Maurya"
tags: ["mdx", "react"]
---

# {frontmatter.title}

By {frontmatter.author}
```

### 3. Create Reusable Components

```tsx
// components/mdx/Callout.tsx
export function Callout({ type = "info", children }) {
  return <div className={`callout callout-${type}`}>{children}</div>;
}
```

Usage in MDX:

```mdx
<Callout type="warning">This is important information!</Callout>
```

### 4. Type Safety

```typescript
// types/mdx.d.ts
declare module "*.mdx" {
  import { MDXProps } from "mdx/types";
  export default function MDXContent(props: MDXProps): JSX.Element;
  export const frontMatter: {
    title: string;
    date: string;
    author: string;
  };
}
```

## Plugins and Extensions

### Remark Plugins (Markdown)

```javascript
// next.config.js
const remarkGfm = require("remark-gfm");
const remarkMath = require("remark-math");

module.exports = withMDX({
  options: {
    remarkPlugins: [remarkGfm, remarkMath],
  },
});
```

### Rehype Plugins (HTML)

```javascript
const rehypeHighlight = require("rehype-highlight");
const rehypeSlug = require("rehype-slug");

module.exports = withMDX({
  options: {
    rehypePlugins: [rehypeHighlight, rehypeSlug],
  },
});
```
